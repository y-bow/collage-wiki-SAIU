We hosted a session on "Open Source and Learning Beyond the Syllabus" conducted by Hari Prasanth S. The session was highly practical and focused on how open source actually works in the real world.

Topics covered included Git & GitHub fundamentals, how pull requests and contributions work, using MkDocs for documentation, and how these tools are used in real-world open-source projects.

{/* truncate */}

The session was open to students from all departments, and it was great to see students asking questions and understanding how open source fits beyond classroom learning. The talk was inspired by the [WikiSyllabus initiative](https://forum.fossunited.org/t/making-college-curricula-accessible/6949) — an open-source Wikipedia of university syllabi — which led to great conversations about making education more open.
